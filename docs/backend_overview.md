# Informe para Desarrollo Backend (TECNOJACK)

He generado un documento maestro (Markdown) que extrae absolutamente **toda la información** configurada en tu aplicación: cada texto, página, vista, paquete de servicios, detalle de entregables y precios.

Dado que la cantidad de información es enorme (el archivo original de datos tiene más de 3700 líneas de código), he volcado todos esos datos en un archivo Markdown estructurado que contiene objetos JSON exactos, para que tu desarrollador Backend pueda copiar, pegar y estructurar la base de datos (SQL o MongoDB) sin perder ningún detalle.

### ¿Qué incluye este archivo maestro?
1. **Categorías de Servicios**: Todas las descripciones y slugs principales.
2. **Configuraciones SEO y Textos de Cabecera**: Para cada página (`Bodas`, `Quinces`, `Grados`, `Videos`, `Corporativos`, etc.).
3. **Paquetes Base**: Todos los paquetes resumidos que se muestran en el grid, con sus características principales.
4. **Detalles de Paquetes (Cotizaciones)**: Todos los sub-paquetes, sus precios base (Ej: 1'900.000 COP), entregables y notas.
5. **Planes de Boda y Servicios Adicionales**: Toda la configuración de extras.
6. **Elementos de Galería y Video**: Las listas de imágenes y videos (con sus URLs y títulos).
7. **Información Global**: Redes sociales, perfil profesional y promesas de marca.
8. **Módulo de Invitaciones (Diana y Juan)**: Estructura recomendada para que el backend cree una colección/tabla de Invitaciones Dinámicas (fechas, mapas, vestidos, invitados).
